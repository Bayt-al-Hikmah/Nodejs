# Node.js Introduction Course

Welcome to the **Node.js Introduction Course** repository by Bayt-al-Hikmah! This collection of lecture notes is designed for beginners and intermediate learners aiming to master Node.js programming fundamentals. Whether you're new to coding or refreshing your skills, these notes provide structured, step-by-step guidance through core concepts.

Bayt-al-Hikmah (House of Wisdom) is dedicated to preserving and disseminating knowledge, inspired by the historic intellectual center of the Islamic Golden Age. These lectures emphasize clear explanations, practical examples, and hands-on exercises to build a strong foundation in Node.js.

## Prerequisites

- Basic familiarity with computers and file management.
    
- No prior programming experience required (though helpful).
    
- Node.js installed (Node.js 16 or later recommended) and a code editor like Visual Studio Code.
    

### Setup Instructions

1. Install Node.js:
    
    - **Windows/Linux/macOS**: Download from nodejs.org.
        
    - Verify installation: Run node -v and npm -v in your terminal.
        
2. Install an editor/IDE: Visual Studio Code with the JavaScript and Node.js extensions is recommended for beginners.
    
3. Test your setup: Run a "Hello, World!" program (example in Lecture 1) using:
    
    ```bash
    node hello_world.js
    ```
    

## Course Overview

This 5-lecture series covers essential Node.js topics progressively. Each lecture includes:

- Theoretical explanations.
    
- Code examples and snippets.
    
- Exercises for practice.
    
- References for further reading.
    


| Lecture   | Topic                                          | Key Concepts Covered                                                                                                    |
| --------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Lecture 1 | Introduction to Node.js and Programming Basics | How computers work, programming languages overview, Node.js setup, user input/output with process.stdin/process.stdout. |
| Lecture 2 | Control Flow and Data Structures               | Strings, arrays, objects, comparison/logical operators, if-else statements, switch-case, for/while loops.               |
| Lecture 3 | Functions and Modules                          | Functions, creating/using modules, managing packages with npm.                                                          |
| Lecture 4 | Object-Oriented Programming and Error Handling | Classes, objects, inheritance, try-catch for error handling.                                                            |
| Lecture 5 | Asynchronous Node.js and File Handling         | Callbacks, Promises, async/await, file I/O with fs module.                                                              |

**Recommended Pace**: 1-2 lectures per week, with time for coding practice. Total estimated time: 15-25 hours.

## Practice and Projects

- **Exercises**: Each lecture ends with coding challenges. Solutions are added in a separate  folder.
    
- **Mini-Project Ideas**:
    
    - Lecture 2: Command-line to-do list using arrays and control flow.
    - Lecture 5: File-based logging system with asynchronous operations.
        
- **Resources**: nodejs.org for documentation, npmjs.com for packages, and Exercism JavaScript track for problems (Node.js is JavaScript-based).
